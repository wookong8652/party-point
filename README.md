# PARTY POINT - 통합 파티 게임 프로젝트

Next.js 15 + TypeScript + Supabase 기반 10인용 파티 포인트 게임입니다.

## 이번 통합 버전에 포함된 기능

- 파티 생성 및 초대 코드, 진행자/참가자 인증
- 최대 10명 참가, 시작 포인트 5,000P
- 실시간 참가자 순위
- 비밀 미션 난이도 선택, 랜덤 배정, 진행자 승인 및 보상
- 주관식 퀴즈 7문제 기반: 10초 답변, 진행자 채점, 정답 +300P
- 홀짝 게임: 100~1,000P 선택, 결과에 따라 총 2배 반환 또는 베팅금 차감
- 비밀경매 1라운드: 최고 비밀 입찰자에게 정답 +1,000P 쿠폰
- 비밀경매 2라운드: 최고 비밀 입찰자에게 베팅 무료권
- 악마의 더블업: 참가비 1,000P, 서버에서 40% 확률 추첨, 성공 시 총 2,500P 지급
- OX 풀배당: 100~1,000P 베팅, 정답자에게 오답 베팅금을 베팅 비율대로 분배
- OX 예외 규칙: 전원 정답이면 잔액 변화 없음(베팅 원금 보존), 전원 오답이면 베팅금 전액 소멸
- 배당 비율 계산의 소수점은 버림
- 베팅 무료권 사용 및 정답 +1,000P 쿠폰의 주관식 퀴즈 적용
- 가위바위보 토너먼트 결과 입력 및 우승 +1,000P / 준우승 +500P 지급
- 자유 선택 게임의 우승자 및 보상 포인트 정산
- 진행자 포인트 수동 지급/차감 및 거래 내역 기록

## 설치 및 실행

1. Node.js 20 이상을 설치합니다.
2. 프로젝트 폴더에서 `npm install`을 실행합니다.
3. Supabase 프로젝트를 준비합니다.
4. Supabase SQL Editor에서 아래 SQL을 순서대로 실행합니다.
   - 기존에 실행한 `supabase/schema.sql`은 다시 실행하지 않습니다.
   - 기존에 실행한 `supabase/game_system.sql`도 다시 실행하지 않습니다.
   - **이번에 추가된 `supabase/full_game_system.sql`을 실행합니다.**
5. 프로젝트 루트에 `.env.local` 파일을 만듭니다.

```env
NEXT_PUBLIC_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=YOUR_PUBLISHABLE_KEY
SUPABASE_SERVICE_ROLE_KEY=YOUR_SECRET_KEY
```

`SUPABASE_SERVICE_ROLE_KEY`는 서버 전용 비밀 키입니다. `NEXT_PUBLIC_` 접두사를 붙이지 말고 GitHub에 업로드하지 마세요.

6. 개발 서버를 실행합니다.

```powershell
npm run dev
```

PowerShell에서 `npm.ps1` 실행 정책 오류가 발생하면 현재 터미널에서 먼저 실행합니다.

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
npm run dev
```

브라우저에서 `http://localhost:3000`으로 접속합니다.

## 게임 진행 방법

- 진행자는 게임 허브에서 게임을 선택하고 시작합니다.
- 참가자는 자신의 화면에서 선택/베팅/참가 신청을 합니다.
- 진행자는 참가 마감 후 결과를 확정합니다.
- 홀짝은 진행자가 주사위 결과(홀/짝)를 선택해 정산합니다.
- 악마의 더블업 성공 여부는 서버가 40% 확률로 추첨합니다.
- OX는 진행자가 질문과 정답을 설정하고, 참가자는 O/X와 베팅 포인트를 제출합니다. 진행자는 마감 후 정산합니다.
- 비밀경매는 입찰 금액이 참가자에게 공개되지 않고, 최고 입찰자에게 해당 쿠폰이 지급됩니다.
- 가위바위보는 실제 대결을 진행한 뒤 진행자가 참가자 중 우승/준우승자를 지정해 보상을 지급합니다.
- 자유 게임은 참가자를 등록한 뒤 진행자가 우승자와 보상 포인트를 입력해 정산합니다.

## 라운드 수

현재 게임 허브는 한 번에 한 게임 세션을 열고 정산하는 방식입니다. 홀짝은 3회, 비밀경매는 2회, OX는 5회 각각 세션을 열어 진행합니다. 주관식 퀴즈는 별도 퀴즈 패널에서 1~7번 문제를 운영합니다.

## OX 풀배당 계산 예시

- 정답자가 있으면 오답자의 실제 베팅금만 풀에 포함합니다.
- 정답자는 자신의 베팅 비율만큼 오답 베팅 풀을 나눠 받습니다.
- 정답자는 원금도 보존됩니다.
- 무료권을 사용한 오답자는 베팅금을 잃지 않으며 풀에도 금액을 보태지 않습니다.
- 정답자가 한 명도 없으면 실제 베팅금은 모두 소멸합니다.
- 오답자가 한 명도 없으면 아무도 추가 포인트를 받지 않고 각자의 원금이 보존됩니다.
- 분배 시 소수점 아래 포인트는 버립니다.

## 주의 및 검증 범위

- 이 ZIP은 전체 소스 프로젝트입니다. `.env.local`, `node_modules`, `.next`는 포함하지 않았습니다.
- 현재 게임 허브는 한 세션씩 시작/마감/정산합니다. OX 5문제와 홀짝 3회는 진행자가 각 라운드를 반복 실행해야 합니다.
- 주관식 퀴즈는 기존 퀴즈 패널을 유지합니다.
- 가위바위보는 실제 토너먼트 진행과 대진표를 자동화하지 않고, 진행자가 참가자를 등록한 뒤 결과를 입력하는 방식입니다.
- 자유 선택 게임도 실제 미니게임은 다시 실행하고 진행자가 결과를 입력하는 방식입니다.
- 포인트 변경과 로그 저장은 여러 DB 요청으로 이뤄지므로, 동시 요청이 매우 많은 공개 서비스로 확대하기 전에는 정산을 PostgreSQL 트랜잭션/RPC로 완전히 원자화하는 추가 작업이 필요합니다.
- 로컬에서 빌드 검증을 마치지 못한 경우, `npm install` 후 `npm run build`를 실행해 오류 여부를 확인하세요.
